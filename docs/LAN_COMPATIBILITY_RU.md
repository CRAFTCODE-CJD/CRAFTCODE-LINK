# Игровая LAN и совместимость игр

Оба игрока заходят в одну игровую комнату LINK и каждый нажимает **Включить игровую сеть Windows**. Когда возле обоих участников появится игровой адрес, один создаёт матч в LAN-меню самой игры. Другой обновляет там список локальных серверов и выбирает матч. Порядок одинаков для установщика и полностью распакованной переносной версии.

## Что проверено на стенде Windows и изолированных сетевых узлах

| Игра или режим | Что удалось подтвердить |
| --- | --- |
| Godot / ENet | Завершён тестовый матч с 16 подключёнными клиентами. У всех совпал итоговый счёт. |
| Игра на Unreal со Steam-поставкой | В двух изолированных копиях игры с включённым IP-драйвером клиент вошёл на игровую карту ведущего. Результат относится к этой конфигурации игры. |
| Epic Online Services Integration Kit | Два игровых процесса с загруженным EIK обменялись данными игрового вызова через IP-драйвер. Облачное лобби требует настроенного продукта Epic и отдельной проверки. |
| Valve GameNetworkingSockets | По прямому IP без запущенного Steam передано и сверено по 65 536 байт в обе стороны. |
| OpenArena / ioquake3 | Клиентский поисковый запрос нашёл настоящий выделенный сервер на одном из четырёх стандартных портов. Сервер ответил на следующий игровой запрос соединения. |
| SuperTuxKart 1.5 | Гость нашёл настоящий Windows-сервер через организатора LINK и получил от игры подтверждение ENet на объявленном нестандартном порту. Соседнему участнику этот порт не открылся. Законченная гонка остаётся отдельной проверкой. |
| C&C Generals | Два клиента нашли матч Alpine Assault через список игр, вошли на карту и получили итоговую статистику обоих игроков после продажи последней базы гостя. |
| C&C Generals: Zero Hour | Воспроизведён пустой список при выборе другой сетевой карты. После исправления LAN IP гость нашёл уже созданный хост, вошёл на карту и доиграл короткий матч. Экраны победы и поражения получены у обоих игроков. |

Проверки различают обнаружение сервера, установление соединения и состоявшийся матч. Успешная проверка UDP подтверждает связь между адаптерами. Для подтверждения совместимости конкретной игры требуется проверить ещё её собственный поиск и вход игрока.

Оба матча C&C проверены на одном ПК с игровыми данными установленных изданий. Для каждого участника запущены отдельный профиль Wine, Windows-клиент [TheSuperHackers weekly-2026-11-06](https://github.com/TheSuperHackers/GeneralsGameCode/releases/tag/weekly-2026-11-06) и сетевое окружение с двумя интерфейсами. Игровые подсети были соединены через две службы LINK и тестовые TUN-интерфейсы. При воспроизведении в Zero Hour LINK доставил все шесть проверенных объявлений ведущего на адаптер гостя, но игра слушала UDP 8086 на другом интерфейсе. После исправления адреса в том же игровом профиле гость увидел ведущего без пересоздания матча. Для игры использовался UDP 8088. Розничный EXE Zero Hour запросил игровой диск. Полный матч с этим EXE и проверка с Wintun на двух физических Windows-ПК остаются открыты.

## Если матч не появился

**Если лобби уже работало, но после старта каждый видит загруженным только себя.** На двух клиентах Zero Hour мы получили это состояние и таймер отсоединения над первой базой при использовании сетевого фильтра LINK 0.7.14. Через UDP 8086 оба игрока вошли в лобби. Пакеты матча на UDP 8088 фильтр отклонял с обеих сторон. После переключения стенда на действующее правило для UDP 8088 во время отсчёта тот же матч продолжился и завершился победой и поражением. Начиная с публичной версии 0.7.17 это правило входит в LINK. Проверьте версию у каждого игрока, включая организатора игровой LAN.

Если разрыв повторяется, скопируйте диагностику с каждого ПК прямо во время отсчёта. В строке «Матч Generals / Zero Hour» можно сравнить исходящий UDP 8088 у одного игрока с входящим у другого. Диагностика также показывает, сколько пакетов пришлось сбросить из очереди отправки и сколько передано по запасному соединению, если эти события происходили.

**Generals и Zero Hour.** В «Подключение → Быстрый запуск игры» выберите `generals.exe` нужной версии (в открытых сборках — `generalsv.exe` для Generals и `generalszh.exe` для Zero Hour) и обычный запуск. Игра предпочитает сохранённый LAN IP, пока он доступен. Иначе она выбирает первый IPv4 по числовому значению. При нескольких сетях им может оказаться адрес другого адаптера. Если LINK обнаружит такое расхождение, «Настроить и запустить» сохранит адрес этого ПК в строке `IPAddress` существующего `Options.ini`. Можно отменить действие или запустить игру без изменений. В уже открытой игре выберите тот же адрес в её сетевых настройках. Для игры в LAN используется поле «LAN IP». [Выбор адреса в коде EA](https://github.com/electronicarts/CnC_Generals_Zero_Hour/blob/main/GeneralsMD/Code/GameEngine/Source/GameClient/GUI/GUICallbacks/Menus/LanLobbyMenu.cpp#L398) · [Перечисление интерфейсов](https://github.com/electronicarts/CnC_Generals_Zero_Hour/blob/main/GeneralsMD/Code/GameEngine/Source/GameNetwork/IPEnumeration.cpp#L52)

| Что видит игрок | Следующее действие |
| --- | --- |
| Windows не включила игровую сеть | Распакуйте Portable целиком, нажмите кнопку включения и ответьте на запрос Windows. Откройте **Подключение → Скопировать диагностику LAN**. Строка «Включение адаптера» показывает, остановился ли запуск на подтверждении, файлах драйвера или настройке адреса. |
| В комнате виден друг, но возле него ещё нет игрового адреса в состоянии готовности | Друг включает игровой адаптер на своём компьютере. В режиме «Только чат» игровые пакеты ему не передаются. |
| LINK сообщает о пересечении сетей | При создании комнаты LINK ищет свободную подсеть по интерфейсам организатора. Адреса сохраняются на время этой комнаты. Если диапазон занят у гостя, новую комнату может создать этот гость. |
| Проверка UDP проходит, но ответов игры на поиск нет | Ведущий должен создать матч в LAN-режиме совместимой версии игры. Если сама игра предлагает выбрать интерфейс, выберите адрес LINK текущей комнаты. На обоих ПК обновите список и сравните диагностику. |
| Ответы поиска приходят, но вход не завершается | Сверьте версию, моды и игровой режим. При наличии функции подключения по IP можно проверить адрес ведущего из комнаты. Сохраните диагностику с обоих ПК после попытки входа. |
| Даже до входа в комнату друзья отображаются вне сети | Проверьте связь на странице друзей. Доступность контакта, включение адаптера и поиск игры проверяются по отдельности. |

## Где нужна поддержка самой игры

LINK передаёт разрешённый IPv4-трафик между участниками комнаты. Для поддерживаемых поисковых протоколов он связывает ответ с запросом игрока и автоматически узнаёт игровой порт. Для неизвестного протокола с нестандартными портами может потребоваться дополнительное правило. Некоторые старые игры используют IPX или широковещание Ethernet, другие ищут миры через multicast или IPv6. Для этих режимов требуется отдельная реализация и проверка. Сеть с запретом прямого UDP также может помешать участникам установить соединение.

Наличие игры в Steam, Epic Games Store или EA app само по себе не определяет совместимость. Разработчик игры выбирает транспорт и способ входа. Для игр с обязательным облачным подбором матчей, авторизацией или проверкой лицензии действуют требования издателя. В библиотеке Valve прямой IP и соединение через инфраструктуру Steam имеют отдельные точки входа.
