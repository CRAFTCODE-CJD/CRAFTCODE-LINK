## Проверка исходного состава для публикации

На отдельной чистой копии выполнена установка 74 пакетов из package-lock.json через npm ci, проверка синтаксиса 248 JavaScript-файлов и 235 тестов без ошибок и пропусков. Тесты native/loopback, native/game-lan и installer/care прошли на Windows. Использованы официальные Node 24.22.1 и Go 1.27.3 с проверенными SHA-256 архивов, отдельными кешами и конфигурацией npm. Локальные out/build-tools и пользовательский npm-конфиг в этой проверке не использовались.

## Доступ и хранение

Список сетей доступен взаимным контактам онлайн. Создатель может отключить запросы. В LAN возврат предоставляется устройству, которое уже участвовало и само вышло. В обычной комнате LINK учитываются действующие правила доступа создателя. Заполненная или завершённая комната недоступна. Удаление или блокировка контакта отзывает его право вернуться.

Вложения используют существующий канал передачи файлов комнаты. Получатель выбирает «Скачать», сохранение завершается после проверки SHA-256. Загрузка у исходного отправителя может проходить через создателя комнаты. Автоматической раздачи скачанного файла нет. Картинки PNG, JPEG, WebP и записи WebM до 8 МиБ можно посмотреть в чате. Длинная запись останавливается через 60 секунд, камера для видеосообщения запрашивается отдельно. Выбранные файлы на ПК автора остаются на своих местах. Записанные в LINK исходники сообщений хранятся в памяти до снятия с публикации или выхода. Скачанные файлы остаются в загрузках получателя.

1. Поставьте 0.7.3 на оба ПК и на ПК организатора, если это третий человек. Вступите в одну **игровую LAN**. Включите игровую сеть на обоих устройствах. Дождитесь статуса «В игровой сети» у обоих.

5. При сообщении об оставшемся устройстве используйте «Восстановить подключение». Сессия другого экземпляра LINK и совпадение имени с чужим устройством обрабатываются отдельно. Для обращения за поддержкой команда ./CHECK-GAME-LAN.ps1 -InspectOnly читает состояние без изменения сети.

### Как работает исправление

При временном сбое интернет-поиска LINK повторяет попытку с увеличивающимся интервалом до минуты. Ручная команда «Обновить связь» повторяет поиск по уже разрешённым маршрутам. Отсутствие ответивших узлов отображается отдельно от присутствия друга. Раннее чтение состояния до загрузки политики больше не перезаписывает сохранённый выбор сетей. В Jabber при входе публикуется присутствие подтверждённым контактам и при обнаружении нового устройства отправляется ответ.

Вход в комнату и чат доступны с выключенным адаптером. После явного включения помощник запрашивает фиксированный GUID, проверяет выданный Windows GUID до назначения IP и настраивает адрес только в активной конфигурации. Он прекращает включение при занятой идентичности, имени или подсети. Приложение допускает отмену и прекращает текущую попытку при выходе из LAN. При штатном завершении помощник заканчивает сеанс и освобождает свой адаптер. Для задержавшегося завершения предусмотрено ограничение ожидания, а повторный запуск заново проверяет занятость.

При обновлении старые записи сетевой истории остаются под управлением Windows. Общий пакет драйвера Wintun может оставаться в системном хранилище. LINK не удаляет драйверы других программ. Установщик и собственный помощник в этой сборке без подписи издателя CRAFTCODE.

### Проверка на Windows

В поставку включён CHECK-GAME-LAN.ps1. На изолированной Windows с доступом на чтение сетевой конфигурации он сравнивает два последовательных цикла включения и выхода, фактический GUID, исчезновение помощника и адаптера, основные маршруты, DNS, другие адаптеры и список профилей после первого цикла. Он выводит результаты в консоль. Файл WINDOWS_TEST_RU.md описывает проверки со сторонним VPN и удалением.

## Принятые решения

- У комнаты один владелец сеанса. Выход создателя завершает комнату для всех. Гость может уйти и снова попроситься в работающую комнату. Во время смены комнаты локальный микрофон и демонстрация предыдущего звонка завершаются.
- Общий каталог сервера не требуется. В списке видны доступные через подтверждённых друзей-создателей комнаты. Старые версии LINK не объявляют комнату; прямые приглашения остаются доступны.
- Файлы можно передавать по частям между добровольно согласившимися участниками. Для будущего обновления требуется подписанный издателем манифест с версией, сроком действия, размером и хешем артефакта и защита от отката. Источник файла не определяет доверие. В этот выпуск вошла только подсказка о более новой версии друга, доступная между клиентами с поддержкой объявления. Торрент-раздача файлов и запуск обновлений от контактов не включены.
